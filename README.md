# gs-front
README - SPA Rede Social de Tecnologia (FuturConnect)

Resumo do Projeto:
Este projeto consiste no desenvolvimento de uma Single Page Application (SPA) que simula uma rede social profissional inspirada no LinkedIn, voltada especificamente para a área de **tecnologia**. O objetivo principal foi criar uma interface moderna, interativa e funcional para fins acadêmicos, demonstrando conhecimentos em desenvolvimento web utilizando ferramentas e frameworks atuais.

Tecnologias Utilizadas:

React + Vite: para criação e otimização da SPA com carregamento rápido e arquitetura moderna.
Tailwind CSS: utilizado para estilização eficiente e design responsivo.
Dark Mode Ativo: o projeto possui modo escuro integrado, proporcionando melhor experiência ao usuário.

Interface:

A aplicação conta com os 60 perfis fictícios de profissionais da área de tecnologia, cada um contendo informações como:
-Nome completo
-Área de atuação / cargo
-Hobby
-Frase curta para bio
-Descrição profissional pública
-skills

Todos os perfis tem opção de avaliar e mandar mensagem ao usuario como foi pedido

Estrutura da SPA

-Componentização utilizando padrões do React.
-Rotas internas gerenciadas como página única (SPA).
-Estilização responsiva com Tailwind CSS.
-DarkMode aplicado.

-Desenvolvimento frontend moderno
-Usabilidade e design responsivo
-Estruturação de SPAs utilizando React
-Simulação funcional de ambiente profissional digital

Como Executar o Projeto:
-bash
Instalar dependências:
npm install

Rodar a aplicação:
npm run dev

A aplicação será iniciada em ambiente local utilizando o Vite.
